# Install and Activate FluentEvent

**FluentEvent** is a WordPress plugin that runs on top of FluentCommunity. Install FluentCommunity first, then add FluentEvent.

## Checking the Requirements

- WordPress 6.7 or newer and PHP 7.4 or newer.
- [FluentCommunity](https://wordpress.org/plugins/fluent-community/) installed and active. The free version is enough.

## Installing FluentEvent

1. Go to **Plugins** › **Add New Plugin** and search for **FluentEvent**, or click **Upload Plugin** and choose the plugin zip.
2. Click **Install Now**.
3. Click **Activate**.

![The WordPress Plugins screen with FluentEvent listed next to FluentCommunity](/images/getting-started/install-activate/1.-Plugins-Screen.webp)

::: warning
Without FluentCommunity, the community features (posting events, the feed and the portal Events page) do not load. Activate FluentCommunity before FluentEvent.
:::

## Opening FluentEvent in the WordPress Admin

After activation, a **FluentEvent** item appears in the WordPress admin menu. Its sub-menu has **Dashboard**, **Add New Event**, **Calendars**, **Events** and **Settings**.

![The FluentEvent item in the WordPress admin menu with its sub-menu expanded](/images/getting-started/install-activate/2.-FluentEvent-Menu.webp)

Open **FluentEvent** › **Dashboard** to see the overview. Only site administrators see this menu.

## Turning On FluentEvent in Your Community

To show events to your members, also turn on FluentEvent in FluentCommunity. See [Enable FluentEvent in FluentCommunity](/enable-fluent-event-in-fluentcommunity). Then continue with [Create your first event](/create-your-first-event).

## What Happens When You Delete the Plugin

Your events, guests and settings are kept when you delete FluentEvent, so reinstalling it does not lose your data.
