# FluentEvent Admin Overview

The **FluentEvent** admin has four areas. **Dashboard**, **Calendars** and **Events** sit in the bar at the top of the screen, and **Settings** is a menu on the right, next to the color theme icon.

You can also open them from the **FluentEvent** sub-menu in the WordPress menu, which adds an **Add New Event** shortcut.


1. **Dashboard**: Totals for events and guests, a guest trends chart, ongoing and upcoming events, and your top events. See [Dashboard and guest stats](/admin-dashboard-and-guest-stats).
2. **Calendars**: The calendars that hold your events. The list groups your **Own calendars** and the **FluentCommunity Spaces** calendars that FluentEvent creates for discussion spaces. See [Calendars overview](/calendars-overview).
3. **Events**: Every event as cards, a timeline or a calendar. See [Events list and views](/manage-events-list-views).
4. **Settings**: A menu with **General** (default events list view, **Public Pages**, email sender details) and **Email Notifications**, which lets you preview each email. See [General settings](/general-settings).

## Finding Common Tasks in the Admin

| I want to | Go to |
| --- | --- |
| Add an event | **Events** › **Add Event** |
| See who is coming | **Events** › open an event › **Guests** tab |
| Check a guest in | An event's **Guests** tab, change the guest's status |
| Add a calendar | **Calendars** › **Create Calendar** |
| Change reminder timing | **Settings** › **Email Notifications** |
| Change the sender name | **Settings** › **General** › **Email** |

## Switching to Dark Mode

The icon at the top right, next to **Settings**, opens the **Color theme** menu. Choose how the FluentEvent admin looks:

- **Light**: The light appearance.
- **Dark**: The dark appearance.
- **System**: Follows your device's light or dark setting.

The icon changes to show the theme you chose. A check mark in the menu marks the current one.
