# FluentEvent Admin Overview

The **FluentEvent** admin has four areas, all reachable from the bar at the top of the screen. You can also open each one from the **FluentEvent** sub-menu in the WordPress menu.

![The FluentEvent dashboard with numbered markers on the Dashboard, Calendars, Events and Settings links](/images/getting-started/admin-overview/1.-Admin-Top-Navigation.webp)

1. **Dashboard**: totals for events and guests, a guest trends chart, ongoing and upcoming events, and your top events. See [Dashboard and guest stats](/admin-dashboard-and-guest-stats).
2. **Calendars**: one calendar per FluentCommunity space. See [Calendars overview](/calendars-overview).
3. **Events**: every event as cards, a timeline or a calendar. See [Events list and views](/manage-events-list-views).
4. **Settings**: the default events view, public landing pages, email sender details and email notifications. See [General settings](/general-settings).

## Finding Common Tasks in the Admin

| I want to | Go to |
| --- | --- |
| Add an event | **Events** › **Add Event** |
| See who is coming | **Events** › open an event › **Guests** tab |
| Check a guest in | An event's **Guests** tab, change the guest's status |
| Add a calendar | **Calendars** › **Create Calendar** |
| Change reminder timing | **Settings** › **Email Notifications** |
| Change the sender name | **Settings** › **General** › **Email** |

## Switching to Dark Mode

The moon icon at the top right switches the FluentEvent admin between light and dark appearance.

## Who Can Open the FluentEvent Admin

The FluentEvent admin is for site administrators. See [Who can manage events](/team-permissions).
