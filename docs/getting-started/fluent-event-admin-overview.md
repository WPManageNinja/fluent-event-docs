# FluentEvent Admin Overview

The **FluentEvent** admin has four areas. **Dashboard**, **Calendars** and **Events** sit in the bar at the top of the screen, and **Settings** is a menu on the right, next to the light and dark mode icon. 

You can also open them from the **FluentEvent** sub-menu in the WordPress menu, which adds an **Add New Event** shortcut.


1. **Dashboard**: totals for events and guests, a guest trends chart, ongoing and upcoming events, and your top events. See [Dashboard and guest stats](/admin-dashboard-and-guest-stats).
2. **Calendars**: the calendars that hold your events, both your own and the ones FluentEvent creates for discussion spaces. See [Calendars overview](/calendars-overview).
3. **Events**: every event as cards, a timeline or a calendar. See [Events list and views](/manage-events-list-views).
4. **Settings**: a menu with **General** (default events view, public landing pages, email sender details) and **Email Notifications**. See [General settings](/general-settings).

When you turn on public landing pages, a **Frontend Portal** link also appears in the top bar and opens your public events page in a new tab.

## Finding Common Tasks in the Admin

| I want to | Go to |
| --- | --- |
| Add an event | **Events** › **Add Event** |
| See who is coming | **Events** › open an event › **Guests** tab |
| Check a guest in | An event's **Guests** tab, change the guest's status |
| Add a calendar | **Calendars** › **Create Calendar** |
| Change reminder timing | **Settings** › **Email Notifications** |
| Change the sender name | **Settings** › **General** › **Email** |

## Switching to Dark Mode

The icon at the top right, next to **Settings**, switches the FluentEvent admin between light and dark appearance. It shows a moon in light mode and a sun in dark mode.

![The FluentEvent dashboard in dark mode with an arrow pointing to the light and dark mode icon next to Settings](/images/getting-started/admin-overview/2.-Dark-Mode.webp)
