# Add an Event to Your Calendar

When you register for an Open event, FluentEvent offers to put the event in your own calendar so you do not forget it.

## Finding the Add to Calendar Links

After you submit the **Register** form on an Open event, a window titled "You're registered" opens. It shows the event's cover image or date, its name, time and place, and an **Add to calendar** section with two choices.

## Choosing Google Calendar or an .ics File

- **Google Calendar**: opens Google Calendar in a new tab with the event's title, start and end time, and location filled in. Review and save it there.
- **Apple / Outlook**: downloads an `.ics` file named after the event. Open it to add the event to Apple Calendar, Outlook or any calendar app that reads `.ics` files.

Click **Done** to close the window.

::: tip
The window opens right after you register. If you close it, add the event by hand using the date and time shown on the event page.
:::

For more on registering, see [RSVP to an event](/rsvp-to-an-event).
