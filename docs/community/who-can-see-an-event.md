# Who Can See an Event

An event post follows the same visibility rules as any FluentCommunity post. FluentEvent adds no separate permissions on the community side, so who sees an event depends on where you posted it.

## Events in a space

Members who can view posts in the space can see its events in the feed, on the **Events** page and on the event page.

- In a **public** space, visitors who are not logged in can see events only if your portal allows public access.
- In a **private** space, only members of that space see the events.
- Members never see events from spaces they cannot access.

## Community-wide events

An event posted without a space is open to every logged-in member. Visitors see it only if your portal allows public access.

## When an event is hidden

An event does not show to anyone in the community when:

- its status is **Draft**. See [Event details and settings](/event-details-and-settings).
- its post is not published or unlisted.
- the member who posted it is blocked, pending or deactivated.

Anyone who opens the link to a hidden event sees the not-found page. The page does not say whether the event exists.

## Public pages

The community rules above apply inside FluentCommunity. Separately, a **Public** or **Unlisted** event in a **Public** calendar also has a public page on your site that anyone can open. See [Public events pages](/public-events-pages).

## Meeting links

Seeing an event does not show the meeting link. On RSVP and Open events, only registered guests see it. See [Meeting link visibility](/meeting-link-visibility).

::: tip
To hide an event for now without losing its guests, set its status to **Draft** in the admin. The guests are kept.
:::
