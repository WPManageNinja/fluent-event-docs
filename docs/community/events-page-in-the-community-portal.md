# Events Page in the Community Portal

The **Events** link in the portal menu opens **All Events**, a page that lists events from across the community. Each space can also show its own **Events** tab. Both are off until you turn them on. See [Turn on Events in your community](/turn-on-events-in-your-community).

## Browsing All, Upcoming and Past Events

Use **All**, **Upcoming** and **Past** to choose which events to list, and **Search events** to find one by name. Load more events with **Load more** when the list is long.

## Switching the Events Page Layout

Three icons switch the layout.

![The portal Events page in Cards view](/images/community/portal-events/1.-Events-Cards.webp)

- **Cards**: a grid of event cards with cover images.

![The portal Events page in Timeline view](/images/community/portal-events/2.-Events-Timeline.webp)

- **Timeline**: events listed by date, with the RSVP button on each.

![The portal Events page in Calendar view showing a month](/images/community/portal-events/3.-Events-Calendar.webp)

- **Calendar**: a month grid. Use **Month**, **Week** and **Day**, the arrows and **Today** to move around.

The view shown first is set in [General settings](/general-settings). If **Disable view change option** is on, members cannot switch.

## Seeing Events Inside a Space

Events posted in a space also show in that space's feed. A space's calendar collects only that space's events, and the space's **Events** tab lists just those.

![A space's feed in the portal showing an event post](/images/community/portal-events/4.-Space-Events.webp)

If there are no events yet, the page says "No events yet". Empty tabs say "No upcoming events" or "No past events".

Administrators also see **Create new event** at the top of the page. See [Create an event from the community portal](/create-an-event-from-the-community-composer).
