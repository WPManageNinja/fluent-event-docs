# Event Page in the Community

Click an event in the feed or on the **Events** page to open its **event page**. It shows everything a member needs to decide and join.

## What the page shows

- The cover image and the event name.
- A **Happening now** badge while the event is running, and an **Ended** badge once it is over.
- **About This Event**: the event description.
- The date and time.
- The place: the venue for an in-person event, or **Online** for an online one.
- The going count, when the event shows it.

## The details box

The details box on the side holds the actions.

- **Interested?** for an RSVP event, **Register** for an Open event, or **Log in to RSVP** for visitors who are logged out. See [RSVP to an event](/rsvp-to-an-event).
- **Join online** for an online event, once you are registered. See [Meeting link visibility](/meeting-link-visibility).
- **Add to calendar** with **Google Calendar** and **Apple / Outlook**. See [Add an event to your calendar](/add-an-event-to-your-calendar).

An event with no registration (**None**) shows no RSVP button, only the details.

## Admin options

Administrators see a menu (**More actions**) on the event with **Edit event**. It opens the event in the FluentEvent admin so you can change it. See [Edit or delete an event](/edit-or-delete-an-event).

Members who are not administrators do not see this menu.

## If the page says it was not found

An event that is a draft, or that sits in a space you cannot see, shows as not found. See [Who can see an event](/who-can-see-an-event).
