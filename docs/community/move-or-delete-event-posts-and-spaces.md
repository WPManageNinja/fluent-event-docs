# Move or Delete Event Posts and Spaces

An event lives inside a FluentCommunity post, so changes to the post or its space also change the event. FluentEvent keeps guests safe in every case.

## Move the post to another space

When you move an event post to another discussion space, the event follows it. The event joins the new space's calendar and its guests stay registered.

- Events can only move to discussion spaces.
- Topics belong to a space, so the old space's topics do not carry over.
- Moving a post to your profile makes it a community-wide event. This needs global posts turned on in FluentCommunity.

## Delete the post

Deleting the post is treated as moderation, not as deleting the event. The event becomes a **Draft** and keeps all its guests. You can then decide in the admin whether to delete it. See [Edit or delete an event](/edit-or-delete-an-event).

## Delete a space

When a discussion space is deleted, its calendar becomes a **Draft** and loses its link to the space. Its events become drafts too and keep their guests. Nothing is removed until you delete it yourself. See [Delete a calendar](/delete-a-calendar).

## Delete the event in the admin

Deleting an event from the FluentEvent admin leaves the community post in place as an ordinary post, without the event card.

## Change an event's calendar

If you move an event to a calendar that belongs to another space, its post moves to that space. If you move it to a site calendar with no space, the post lets go of the event and stays as a plain post.

::: warning
Deleting an event from the admin also removes its guests. To keep them, set the event to **Draft** instead.
:::
