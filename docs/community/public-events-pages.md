# Public Events Pages

**Public events pages** let anyone browse your public calendars and open an event without logging in to FluentCommunity. They are separate from the community portal and are off by default.

## Turn them on

1. Go to **FluentEvent** › **Settings** › **General**.
2. Turn on **Enable landing pages**.
3. Check the **Portal slug**. The default is `events`, so the page is at `yoursite.com/events`.
4. Click **Save Settings**.

See [General settings](/general-settings) for every option on this screen.

## What visitors see

- A list of **public** events from all your public calendars. When you have more than one public calendar, a chip for **All** and one for each calendar let visitors filter the list.
- A page for each event, at `yoursite.com/events/<event-slug>`.

The list follows your default view. Visitors can switch the view unless you turned on **Disable view change option**.

## What is shown

Only events in a calendar whose status is **Public** appear. The list shows events with the **Public** visibility. An **Unlisted** event is not in the list but opens from its direct link. Private and draft calendars and events show a not-found page, the same one as an event that does not exist.

## Register from a public page

Visitors cannot RSVP as members, because there is no account. They register on Open events with a name and email. See [RSVP and Open modes](/event-entry-modes-rsvp-and-open).

::: warning
Changing the **Portal slug** breaks links people already have. Choose it before you share the page.
:::
