# Calendars Overview

A **calendar** holds events. Every event belongs to one calendar. You can create your own calendars, and FluentEvent also creates calendars for your FluentCommunity spaces. Open **FluentEvent** › **Calendars** to see them all.

## Understanding Where Calendars Come From

- **Your own calendars**: Calendars you create yourself, for example **Workshops & Training**. Use them for events that are not tied to a space.
- **Space calendars**: FluentEvent creates a calendar for a discussion space the first time an event is posted in that space from the community portal. The calendar takes the space's name and starts as **Private**.
- **Community calendar**: Events posted community-wide, outside any space, go into one calendar called **Community**. It also starts as **Private**.

An event you create from the WordPress admin can use any calendar, but it is not posted in the community feed. See [Create an event from the admin](/create-an-event-from-the-admin).

If you delete a space in FluentCommunity, its calendar is not deleted. FluentEvent detaches it and sets it to **Draft**. Its events become drafts and keep their guests, so you can decide what to delete.

## Viewing the Calendars List

The list groups your calendars under two headings: **Own calendars** and **FluentCommunity Spaces**. The community calendars are listed under **FluentCommunity Spaces**, with the FluentCommunity logo next to the heading.

![The Calendars screen listing four own calendars and four FluentCommunity space calendars](/images/calendars/overview/1.-Calendars-List.webp)

- **Status filters**: **All**, **Public**, **Private** and **Draft**, each with a count.
- **Search calendars**: Type a name and press <kbd>Enter</kbd> to find a calendar.
- **List and card view**: Use the two icons next to the search box to switch the layout. FluentEvent remembers your choice.
- **Each row**: Shows the calendar's color, name and slug, its status, how many events and guests it has, an **Add Event** shortcut and a menu with more actions.

![The Calendars screen in card view with each calendar as a card](/images/calendars/overview/2.-Calendars-Cards.webp)

## Using the Calendar Row Actions

Use a row's menu to take quick actions without opening the calendar.

- **Status**: Click the status tag on a row and choose **Public**, **Private** or **Draft** to change it right away.
- **Add Event**: Opens the event form with this calendar already selected.
- **Edit**: Opens the calendar's edit form.
- **View in Community**: Opens the space in a new tab. It appears only on calendars that belong to a space.

## Understanding Calendar Statuses

- **Public**: Anyone can find it. Events in a public calendar can have a public page. See [Event details and settings](/event-details-and-settings).
- **Private**: No public page.
- **Draft**: Not ready yet.

An event has a public page only when the event is **Public** or **Unlisted** and its calendar is **Public**. Calendars themselves have no public page.

## Opening a Calendar's Detail Page

Click a calendar's name, or anywhere on its row, to see its detail page.

The page shows the calendar's title and status, its slug and who created it, four totals and two tabs. Calendars that belong to a space show the FluentCommunity logo next to the title. Click it to open the space in a new tab. The Community calendar shows the same logo with a note that it holds community-wide events.

- **Total Events**, **Upcoming Events**, **Total Guests** and **Checked In Guests**: The four totals for this calendar.
- **Events**: The calendar's events, with **All**, **Upcoming** and **Past** buttons and the same views as the main [Events list](/manage-events-list-views).
- **Settings**: The **Danger Zone** for [deleting the calendar](/delete-a-calendar).

Use **Edit** to change the calendar and **Add Event** to create an event in it. See [Create and edit a calendar](/create-and-edit-a-calendar).
