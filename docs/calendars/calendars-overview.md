# Calendars Overview

A **calendar** holds events. Every FluentCommunity space gets its own calendar, so the events posted in a space live in that space's calendar. Open **FluentEvent** › **Calendars** to see them all.

![The Calendars screen listing five calendars grouped under FluentCommunity Spaces](/images/calendars/overview/1.-Calendars-List.webp)

## Viewing the Calendars List

- **Status filters**: **All**, **Public**, **Private** and **Draft**, each with a count.
- **Search calendars**: find a calendar by name.
- **FluentCommunity Spaces**: calendars that belong to your spaces are grouped under this heading.
- **Each row** shows the calendar name and slug, its status, how many events and guests it has, an **Add Event** shortcut and a menu with more actions.

## Understanding Calendar Statuses

- **Public**: anyone can find it. Public calendars can appear on [landing pages](/general-settings) when you turn them on.
- **Private**: no public page.
- **Draft**: not ready yet.

## Opening a Calendar's Detail Page

Click a calendar to see its detail page.

![A calendar detail page with event and guest totals and the list of its events](/images/calendars/overview/2.-Calendar-Detail.webp)

The page shows the calendar's status, slug and who created it, four totals (**Total Events**, **Upcoming Events**, **Total Guests**, **Checked In Guests**) and two tabs:

- **Events**: the calendar's events, with **All**, **Upcoming** and **Past** buttons and the same views as the main [Events list](/manage-events-list-views).
- **Settings**: the Danger Zone for [deleting the calendar](/delete-a-calendar).

Use **Edit** to change the calendar and **Add Event** to create an event in it. See [Create and edit a calendar](/create-and-edit-a-calendar).
