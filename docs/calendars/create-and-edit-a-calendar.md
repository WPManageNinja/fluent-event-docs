# Create and Edit a Calendar

Create a calendar when you need another group for events, for example one for workshops and one for webinars. Space calendars are created for you, and you can edit them like any other.

## Creating a New Calendar

1. Go to **FluentEvent** › **Calendars**.
2. Click **Create Calendar**.

![The Calendars screen with an arrow pointing to the Create Calendar button](/images/calendars/create-edit/1.-Create-Calendar-Button.webp)

3. Fill in the form.
4. Click **Create Calendar**.

The form opens with the note "A calendar holds your events. Give it a title and you can start adding events to it." Click **Go Back** to leave without saving.

![The Create Calendar form with title, slug, color and visibility](/images/calendars/create-edit/2.-Create-Calendar-Form.webp)

### Setting the Calendar Identity

The **Identity** section holds the name and color people see wherever the calendar appears.

- **Title** (required): The name people see, for example `Personal`. It can be up to 100 characters.
- **Slug** (required): Identifies the calendar in links, for example `personal`. FluentEvent fills it in from the title as you type, using lowercase letters and hyphens. You can change it before you save.
- **Color**: Pick one of the swatches (Vivid Blue, Purple, Deep Lilac, Cyan, Emerald Green, Lime Green, Amber or Red-Orange), or click **+** to choose a custom color. The color marks the calendar's events. A custom color must be a hex value such as `#0099ff`.

### Choosing Calendar Visibility

The **Visibility** section decides who can find the calendar. **Public** is selected by default.

- **Public**: Anyone can find it.
- **Private**: No public page.
- **Draft**: Not ready yet.

Visibility also affects the events inside. An event has a public page only when its calendar is **Public**. See [Calendars overview](/calendars-overview).

Click **Reset Calendar** to clear the form, then click **Create Calendar** to save.

## Editing an Existing Calendar

1. Open the calendar and click **Edit**, or choose **Edit** from the menu on its row in the list.
2. Change the title, color or visibility.
3. Click **Update Calendar**.

The edit form says "Update the calendar details. Events already in it are not affected." Changing a calendar's title, color or visibility does not move or change its events.

![The Edit Calendar form for the Events and Meetups calendar](/images/calendars/create-edit/3.-Edit-Calendar-Form.webp)

You can also change a calendar's visibility from the list. Click the status tag on its row and choose a new status. See [Calendars overview](/calendars-overview).

## Changing a Calendar's Slug

The slug is locked when you edit, because links to the calendar use it.

1. Click **Change** next to the slug.
2. Read the message and click **Change slug** to confirm.
3. Enter the new slug and click **Update Calendar**.

![The Change slug confirmation asking whether to change the slug of the calendar](/images/calendars/create-edit/4.-Change-Slug-Dialog.webp)

::: warning
Changing the slug later breaks existing links to the calendar.
:::

Next, [add events to the calendar](/create-an-event-from-the-admin). Use **Add Event** on the calendar's row or detail page to start with the calendar already selected.
