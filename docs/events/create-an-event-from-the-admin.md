# Create an Event from the Admin

Use the **Add Event** form in **FluentEvent** to create an event from the WordPress admin. The event is posted in the FluentCommunity space that belongs to the calendar you choose.

::: tip
You can also create events from the community portal. See [Create an event from the community portal](/create-an-event-from-the-community-composer).
:::

## Open the form

1. Go to **FluentEvent** › **Events**.
2. Click **Add Event**.

![The Events screen with an arrow pointing to the Add Event button](/images/events/create-event-admin/1.-Events-List.webp)

You can also use **FluentEvent** › **Add New Event** in the WordPress menu. An event needs a calendar, so if you have none the form asks you to create one first. See [Create and edit a calendar](/create-and-edit-a-calendar).

## Fill in the form

The form has sections, from top to bottom.

![The Create Event form showing the cover image, basics and visibility sections](/images/events/create-event-admin/2.-Create-Event-Form.webp)

1. **Cover image**: optional. It shows on the event page and on event cards.
2. **Basics**: enter the **Event name** (required) and choose the **Calendar** (required).
3. **Visibility**: choose **Public**, **Unlisted**, **Private** or **Draft**.
4. **Description**: optional. This appears on the event page.
5. **Date and time**: set **Start**, **End** and **Timezone**.
6. **Venue type**: choose **In person** or **Online**.
7. **Registration**: choose the **Entry type** and whether to **Show how many guests are going**.

![The Basics section with the event name highlighted and the calendar selected](/images/events/create-event-admin/3.-Basics-Section.webp)

Every field is explained in [Event details and settings](/event-details-and-settings).

## Choose how guests join

![The Registration section with the RSVP, Open and None entry types](/images/events/create-event-admin/4.-Registration-Section.webp)

**RSVP** is selected by default. See [RSVP and Open modes](/event-entry-modes-rsvp-and-open) to compare the three types.

## Save

Click **Create Event**. The form checks that the event has a name, that the end is after the start, and that an online event has a meeting link.
