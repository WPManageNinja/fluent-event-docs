# Create an Event from the Community Portal

Administrators can create events without leaving the FluentCommunity portal. The **Create new event** button on the portal's Events page opens a full event form. An event created this way is posted in the community, so members see it in the feed and on the Events page.

::: tip
Only administrators see the **Create new event** button. Members can RSVP but cannot create events. Events can be posted only in discussion spaces, not in course spaces.
:::

## Opening the Event Form in the Portal

1. In the portal, open **Events**. If you do not see it, [turn on the Events menu item](/turn-on-events-in-your-community) first.
2. Click **Create new event**, at the top right of the **All Events** page.

![The community portal Events page with an arrow pointing to Create new event](/images/events/portal-composer/1.-Create-New-Event-Button.webp)

## Filling In the Portal Event Form

The **Create Event** page has sections from top to bottom.

1. **Where do you want to post this event?** Choose where members will see the event.
    - **In a space**: Only members of that space see it. Pick the discussion space.
    - **Community-wide**: The event is posted on your profile, outside any space, and everyone in the community can see it. This needs global posts turned on in FluentCommunity under **Portal Settings** › **General** › **Global Post Status**. Otherwise the option shows as turned off.
2. **Feed post**: Write the text members see in the feed, above the event. It is optional.
3. **Cover image**: Click **Click to add a cover image**. It shows at the top of the event page and on event cards.
4. **Basics**: Enter the **Event name** (required), for example `Friday Q&A`.
5. **Description** (optional): Add details with the editor. It has **Visual** and **Code** tabs and an **Add image** button.
6. **Date and time**: Set the **Start** and **End** date and time, and the **Timezone**.
7. **Venue type**: Choose **In person** and fill in the venue and address, or choose **Online** and paste a meeting link.
8. **Entry type**: Choose **RSVP**, **Open** or **None**.
9. Click **Create Event**.

The portal form has no **Calendar** or **Visibility** field. FluentEvent puts the event in the calendar of the space you chose, and creates that calendar if the space does not have one yet. A community-wide event goes into the global **Community** calendar. See [Event details and settings](/event-details-and-settings) for every field, and [RSVP and Open modes](/event-entry-modes-rsvp-and-open) to choose the entry type.

![The Create Event page in the community portal](/images/events/portal-composer/2.-Create-Event-Page.webp)

## Checking What the Form Validates

Before the event is posted, the form checks that:

- The event has a title.
- The end is after the start.
- An online event has a meeting link.

If a check fails, the form shows a message. Fix the field and click **Create Event** again.

## Finding the Event After You Post It

Once saved, the event shows in the feed as described in [Events in the community feed](/events-in-the-community-feed). It also appears on the portal Events page. See [Events page in the community portal](/events-page-in-the-community-portal). To change or remove it later, see [Edit or delete an event](/edit-or-delete-an-event).
