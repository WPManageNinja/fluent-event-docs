# Events List and Views

**FluentEvent** › **Events** lists every event. Switch between three views, search by name and filter the list to find what you need. To add an event, click **Add Event**. See [Create an event from the admin](/create-an-event-from-the-admin).

## Filtering by All, Upcoming and Past

Use the **All**, **Upcoming** and **Past** buttons at the top right.

- **All**: Every event, whatever its date.
- **Upcoming**: Events that have not ended yet.
- **Past**: Events that have already ended.

**Upcoming** is selected the first time you open the screen. After that, FluentEvent remembers your last choice in your browser. Past events appear once they have ended.

## Choosing a List View

The three icons next to the search box switch the view: **Cards**, **Timeline** and **Calendar**. FluentEvent remembers the view you pick. The first view you see comes from the default set in [General settings](/general-settings).

### Using the Cards View

Each event is a card with its cover image, date, calendar, status and place. An online event shows **Online**, and an in-person event shows **In person**. An event that runs for more than one day also shows how many days it lasts, for example "3 days".

Click a card to open a side panel with the event's details. Click **View Full Details** there to open the event page.

![The Events screen in Cards view](/images/events/list-views/1.-Cards-View.webp)

### Using the Timeline View

Events are listed by date. Each shows its calendar, time, status, whether it is online or in person, and two buttons: **Manage Event** and **Edit Event**. Events posted from the community portal also show a link that opens their community post in a new tab.

![The Events screen in Timeline view](/images/events/list-views/2.-Timeline-View.webp)

### Using the Calendar View

A month grid shows each event on its day. Use the **Month**, **Week** and **Day** buttons to change the range, the **Previous** and **Next** arrows to move, and **Today** to jump back to the current date.

- A multi-day event appears on every day it covers, labeled **Day 1**, **Day 2** and so on.
- When a day has more events than fit, the cell shows a **more** link with the number that are hidden.
- Click an event to open the same side panel, then **View Full Details** for the event page.

![The Events screen in Calendar view showing a month](/images/events/list-views/3.-Calendar-View.webp)

## Reviewing Past Events

Click **Past** to see events that have already ended. You can still open them to review their guests. If there are none yet, the list shows **No past events** and explains that events show up once they end.

![The Events screen filtered to past events](/images/events/list-views/4.-Past-Events.webp)

## Searching and Filtering Events

Type in **Search events** to find an event by name. Click the funnel icon to open the filter panel.

- **Status**: **All**, **Public**, **Unlisted**, **Private** or **Draft**.
- **Calendar**: Show events from one calendar. See [Calendars overview](/calendars-overview).
- **Date range**: Set **From** and **To**, then click **Apply**. This filter is not available in the calendar view, which uses the month you are viewing.

Active filters appear as chips above the list. If nothing matches, the list shows **No events found**. Remove a chip to widen the results again.

![The filter panel with status, calendar and date range options](/images/events/list-views/5.-Filter-Panel.webp)

## Opening an Event from the List

Click **Manage Event** to open the event's page with its guests, or **Edit Event** to change its details. See [Edit or delete an event](/edit-or-delete-an-event).
