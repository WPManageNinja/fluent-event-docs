# Edit or Delete an Event

Each event has a detail page with four tabs and an **Edit Event** button. Use it to review an event, change it or delete it.

## Opening an Event to Manage It

1. Go to **FluentEvent** › **Events**.
2. Click **Manage Event** on the event you want.

The event page opens with a breadcrumb back to **Events**, the cover image and these tabs:

- **Overview**: The **Status**, the **Registration Type**, the date and time, the venue (or the meeting link for an online event), the calendar and the **Public page**. If the event's timezone differs from your site's, the page shows the time in both. Click the calendar name to open that calendar.
- **Description**: The event description. If it is empty, the tab says **No description yet** and offers **Add Description**.
- **Guests**: The guest list. See [Manage event guests](/manage-event-guests).
- **Settings**: The **Danger Zone** for deleting the event.

The **Public page** row shows the event's public link, with a **Copy link** button next to it. Only **Public** and **Unlisted** events have a public page, and only when their calendar is public. Otherwise the row explains why there is no page, for example that the calendar is not public.

![An event detail page with the Edit Event button highlighted](/images/events/edit-delete/1.-Event-Detail.webp)

## Editing Event Details

1. Open the event and click **Edit Event**.
2. Change what you need.
3. Click **Update Event**.

The form is the same as when you created the event. See [Event details and settings](/event-details-and-settings) for every field. Guests already registered are not affected.

![The Edit Event form with the current details filled in](/images/events/edit-delete/3.-Edit-Event-Form.webp)

You can also click **Edit Event** on any event in the list. To edit from the community portal instead, see the next section.

If you change the start time, reminder emails are rescheduled for the new time. See [Event reminder emails](/event-reminder-emails). To hide an event while you rework it, set **Visibility** to **Draft**, then set it back to **Public** when you are ready.

## Editing an Event from the Community Portal

Administrators can edit an event without leaving the community portal.

1. Open the **Events** page or the event page in the portal.
2. Click **More actions** on the event.
3. Choose **Edit event**.
4. Change what you need.
5. Click **Update Event**.

The **Edit Event** page has the same fields as the create form, without the space and feed post sections. A note at the top says "To change the post text or its space, edit the post itself." Click **View post** to open the post.

![The Edit Event page in the community portal with the notice about editing the post](/images/events/edit-delete/4.-Edit-Event-In-Portal.webp)

## Deleting an Event from the Danger Zone

Delete an event only when you are sure. There is no undo.

1. Open the event and go to the **Settings** tab.
2. In the **Danger Zone**, find **Delete this event**.
3. Type the event name in the box to confirm.
4. Click **Delete Event**.
5. Click **Delete** in the confirmation box.

After the delete, FluentEvent returns you to the events list.

![The Danger Zone on the event Settings tab](/images/events/edit-delete/2.-Event-Settings-Tab.webp)

If you posted the event from the community portal, its feed post stays in the space as a plain post without the event card.

::: warning
Deleting an event is permanent. The event and all of its data, including guests, are removed and cannot be recovered.
:::
