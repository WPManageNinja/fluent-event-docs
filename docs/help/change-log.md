# Changelog

## FluentEvent v1.0.0

*Released on November 12, 2026*

::: code-group

```md [🆕 New Features]
• Initial release.
• Events posted in FluentCommunity discussion spaces, with a calendar for each space.
• RSVP and Open entry modes, with an optional guest count.
• Guest management: add, edit, remove and check in guests.
• Confirmation, cancellation and reminder emails.
• Add to Google Calendar and Apple Calendar.
• Admin dashboard with card, timeline and calendar views.
```

:::
